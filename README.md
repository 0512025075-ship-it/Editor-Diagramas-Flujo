# Editor-Diagramas-Flujo
El Editor Visual de Diagramas de Flujo es una aplicación de escritorio desarrollada en Java Swing y AWT bajo el patrón de arquitectura Modelo-Vista-Controlador.

Su propósito principal es brindar un entorno interactivo donde un usuario puede diseñar, conectar, validar y exportar diagramas de flujo algorítmicos. La aplicación abarca desde el modelado visual dinámico (crear, arrastrar, renombrar y enlazar bloques con el ratón) hasta la persistencia de datos (guardado binario de proyectos) y el procesamiento de lógica formal (validación de consistencia estructural del diagrama y traslación automática a pseudocódigo ejecutable).
